# Двусвязные списки слов: C и NASM x86-64

Одна и та же задача, решённая дважды: на **C** и на **ассемблере NASM** (x86-64, Linux).

## Задача

На вход подаётся последовательность слов через запятую, в конце стоит точка, например:

```
cat,dog,bird,cat,ant,horse.
```

Программа раскладывает слова по длине (от 1 до 8 символов) в отдельные
**отсортированные двусвязные списки** и выводит каждое слово с числом его повторений:

```
ant col-vo: 1
cat col-vo: 2
cat col-vo: 2
dog col-vo: 1
bird col-vo: 1
horse col-vo: 1
```

## Структура

```
c/word_lists.c          # решение на C
nasm/
├── source/sem.asm      # точка входа (main)
├── source/macro.c      # вспомогательные функции ввода-вывода
├── parse.inc           # чтение и разбор входа
├── create_node.inc     # создание узла списка
├── insert.inc          # вставка с сохранением сортировки
├── print_list.inc      # вывод списка
├── macro.inc, io64.inc # макросы
└── makefile
```

## Сборка и запуск

C:

```bash
gcc c/word_lists.c -o c/word_lists
echo "cat,dog,bird,cat,ant,horse." | ./c/word_lists
```

NASM (нужны `nasm` и `gcc`, Linux x86-64):

```bash
cd nasm
make
echo "cat,dog,bird,cat,ant,horse." | ./bin/program
```

## Что показывает проект

- работа с динамической памятью (`malloc`) и указателями;
- реализация двусвязного списка с упорядоченной вставкой;
- соглашение о вызовах System V AMD64, выравнивание стека, вызов функций libc из ассемблера.
